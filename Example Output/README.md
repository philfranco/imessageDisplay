# Example Output

This folder contains a sample iMessage archive generated by the exporter. All names, phone numbers, messages, and call records are made up.

Open [`index.html`](./index.html) in a browser to explore the sample conversations, search page, inferred birthday calendar, birthday-wishes search, and call history. On the birthday-wishes page, try entering `2000-06-10` to see example wishes from multiple years and group chats.

To regenerate every example page after changing the exporter, run `python generate_example_output.py` from the repository root. The sample pages are static and do not require a web server.
