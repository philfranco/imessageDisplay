# Example Output

This folder contains a sample iMessage archive generated by the exporter, with eight fictional conversations and 69 sample messages. All names, phone numbers, messages, and call records are made up.

Open [`index.html`](./index.html) in a browser to explore the sample conversations, search page, inferred birthday calendar, birthday-wishes search, and call history. On the birthday-wishes page, try entering `2000-06-10` to see example wishes from multiple years and group chats.

The sample pages are static and do not require a web server.
